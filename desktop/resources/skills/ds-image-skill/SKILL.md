# DS Image Skill

这个 skill 负责把文字提示词转成图片。它不替代主模型：主模型负责理解用户意图、组织提示词，然后调用本技能出图，再把结果和图片位置告诉用户。

## 何时使用

- 用户用自然语言要求产出图片时使用，例如：“画一只小猫”“生成一张海报”“帮我画个头像”“做一张产品概念图”“来一张星空壁纸”“给文章配个图”。
- 用户上传图片并提出修改要求时使用，例如：“把这张图的背景换成星空”“把照片变成动漫风格”“把这只猫改成戴帽子”“把这个 logo 换个配色”。
- 与当前选中的聊天模型无关：任何支持工具调用的聊天模型都可以调用本技能。

## 触发原则（重要）

- 用户用自然语言表达需求时**直接执行**，不要反问“是否需要调用某个技能”或“要用哪个模型”，也不要让用户提供技能名、脚本名或模型名。
- 用户未指定模型时使用默认 `qwen-image-2.0`；未指定尺寸/风格时按提示词内容自行判断即可。
- 用户上传图片要求修改时，**自动**走「识图理解 + 文生图」两步流程（见下文），不要打断用户询问步骤。
- 生图成功后，把图片保存位置告诉用户即可；如果用户在对话界面能直接看到图片，简短说明一句即可，不要长篇解释内部过程。
- 拿不准用户意图时，可参考 `references/triggers.md` 里的常见说法；只要用户想要一张新图或想修改某张图，就属于本技能职责。

## 调用方式

```powershell
scripts/image-generate.ps1 -Prompt "<中文或英文提示词>" -Model qwen-image-2.0 -OutDir "<workspace>/images" -Filename "demo.png"
```

- `-Model`：`qwen-image-2.0`（默认，写实与文字渲染均衡）或 `wan2.7-image`。用户未指定时默认用 `qwen-image-2.0`。
- `-OutDir`：图片保存目录，默认使用当前工作目录下的 `images` 文件夹（会自动创建）。
- `-Filename`：可选输出文件名（含扩展名），缺省自动生成 `generated-<时间戳>.png`。
- `-NoOpen`：可选，禁止生成后自动打开图片。默认生成成功后会自动用系统默认看图程序打开图片。

## 图生图（上传原图改图）流程

底层生图模型只接受文字提示词（基元律动当前不支持参考图参数），所以“图生图”通过两步间接实现：

1. **识图**：先调用 ds-vision-skill（或其他可用的识图能力）识别用户上传的原图，提取原图的主体、构图、风格、配色、光线、画面细节、文字内容等结构化描述。
2. **合并提示词**：把「原图描述 + 用户的修改要求」合并成一条完整、具体、可执行的生图提示词。例如用户要求“把小猫改成蓝色背景”：提示词应包含原图的主体与风格描述，再加上背景颜色变化。
3. **生图**：调用本技能出图，保存到工作区。

示例（提示词组合思路）：

```text
原图：一只橙色小猫坐在窗台上，扁平插画风格，柔和光线，浅色背景。
修改要求：背景改成星空夜景。
合并后提示词：一只橙色小猫坐在窗台上，扁平插画风格，背景改为深蓝色星空夜景，点缀星星与月亮，画面保持柔和光线。
```

注意：这种间接改图是对原图的理解性重绘，无法逐像素保留原图内容。用户要求严格保留原图（如证件照、商标、复杂版式、需精确还原的文字）时，要如实说明限制，并建议改用专业图像编辑工具。

## 输出

脚本始终输出一行 JSON：

```json
{"status":"ok","provider":"tokenrhythm","model":"qwen-image-2.0","path":"...","mime_type":"image/png","size_bytes":123,"cost_cny":"0.20"}
```

失败时：

```json
{"status":"error","code":"NO_API_KEY|HTTP_ERROR|BAD_RESPONSE|DOWNLOAD_FAILED|UNEXPECTED","message":"..."}
```

- `status=ok`：图片已自动打开（系统默认看图程序），同时把 `path` 对应的保存位置告诉用户；若 `opened` 为 `false` 表示自动打开失败，仅告知路径即可。
- `status=error` 且 `code=NO_API_KEY`：提醒用户在 设置 → 模型 → 生图能力 卡片中配置基元律动 API Key。
- `status=error` 且 `code=HTTP_ERROR`：把 `message` 里的服务商提示转达给用户，可能是余额不足、限流或参数问题。

## 计费与配置

- 每生成一张图片按张计费（约 ¥0.2/张，以服务商为准），需要基元律动账户余额充足。
- API Key 在应用内 设置 → 模型 → 生图能力 卡片配置，保存后应用会自动写入本技能的 config.json，无需手动编辑。
- 未配置 Key 时先提示用户配置，不要反复重试。

## 隐私

- 提示词会发送给基元律动（TokenRhythm）的生图服务。涉及隐私、合同、证件等敏感内容时，先征求用户确认。

## 维护约定

- PowerShell 脚本源码保持 ASCII-only，中文通过参数传入。
- 面向用户的 Markdown 文档使用 UTF-8。
