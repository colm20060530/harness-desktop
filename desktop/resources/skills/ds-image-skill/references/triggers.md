# 生图 / 改图 自然触发说法库

下面是用户最常见的生图、改图说法。用户用任意类似说法提出需求时，都应直接执行，
不要要求用户说明“用什么技能”或“什么模型”。说法不限于此表，重点是判断「用户想要一张新图片，或想修改某张图片」。

## 文生图（直接画）

- 画一张… / 帮我画… / 画个… / 画一只小猫 / 画个美女 / 画个风景
- 生成一张… / 生成一个… / 生成一幅… / 创作一幅… / 来一张…
- 做一张… / 做个… / 设计一个… / 设计一张…
- 帮我画个头像 / 做个头像 / 生成头像 / 画个微信头像
- 做个 logo / 设计个标志 / 画个品牌 logo
- 做一张海报 / 生成海报 / 做个封面 / 设计个封面 / 做个横幅 / 做个 banner
- 做个壁纸 / 来一张壁纸 / 生成手机壁纸 / 做个电脑壁纸
- 给文章配个图 / 配图 / 插图 / 生成配图
- 做个表情包 / 生成表情包 / 画几个表情包
- 画个插画 / 漫画 / 简笔画 / 写实图 / 动漫风格 / 水墨风 / 国风 / 赛博朋克风 / 油画风 / 水彩风 / 像素风
- 生成概念图 / 产品图 / 效果图 / 示意图 / 设计稿 / 原型图
- 画一张关于…的图 / 我想要一张…的图 / 帮我画一幅…的画

## 图生图 / 改图（上传图片后修改）

- 把这张图的背景换成… / 换个背景 / 换背景 / 背景改成…
- 把照片变成动漫风格 / 变成油画风格 / 变成水墨风 / 换个风格
- 给这只猫戴上帽子 / 加上… / 去掉… / 把…删掉
- 把颜色改成… / 换个配色 / 调个色 / 改成黑白的 / 变成复古色调
- 把这张照片改成… / 按这张图再画一张 / 照着这张图生成 / 参考这张图 / 基于这张图
- 美化一下这张图 / 修复这张图 / 增强一下画质 / 把图变清晰
- 把图片放大 / 扩图 / 加宽画面 / 补全画面
- 换个人物 / 换掉背景里的… / 把里面的…换成…
- 这张图不好看，重新画一版 / 换一种构图 / 改一下布局
- 把这张图做成海报 / 做成头像 / 做成壁纸
