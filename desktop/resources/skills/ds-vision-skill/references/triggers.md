# 识图自然触发说法库

下面是用户最常见的识图/视觉提问说法。用户用任意类似说法提出需求时，都应直接执行识图，
不要要求用户说明“用什么技能”或“什么模型”。说法不限于此表，重点是判断「用户上传了图片/截图/文档，并想了解其内容」。

## 通用看图 / 描述

- 这是什么 / 这是什么图片 / 这张图里是什么 / 这张图片里是什么 / 图片里有什么 / 图里有什么
- 帮我看看这张图 / 帮我看看这张图片 / 帮我看下这张图 / 看一下这个 / 帮我瞅瞅这张图
- 描述一下这张图 / 描述这张图片 / 详细描述一下 / 给我讲讲这张图 / 介绍一下这张图
- 这张图讲了什么 / 图片的内容是什么 / 图里发生了什么事 / 帮我分析一下这张图
- 看看图片里有什么东西 / 图片里都有什么 / 这张图上有哪些内容
- 这张图是不是… / 图片里有没有… / 帮我确认一下图片里有没有…
- 这个图片是什么意思 / 这个图想表达什么 / 帮我理解一下这张图
- 总结一下这张图的内容 / 用几句话概括这张图
- 这张照片拍的是什么 / 这张照片是什么场景 / 照片里是什么地方

## OCR / 文字识别

- 图片里写了什么字 / 图上有哪些文字 / 识别图中的文字 / 提取图片里的文字 / 把图里的字读出来
- OCR 一下 / 帮我 OCR / 识别一下这个截图里的文字 / 图片里的字是什么
- 把这张图上的字打出来 / 图片中的文案是什么 / 帮我读一下图片里的文字
- 识别票据/发票/收据/小票上的字 / 识别证件上的文字

## 截图分析

- 分析这个截图 / 解读这个截图 / 这个截图是什么意思 / 看看这个截图的报错
- 这个报错信息是什么 / 帮我看看这个错误截图 / 这是什么错误
- 分析这个聊天记录截图 / 这个页面截图是什么 / 帮我看看这个界面
- 这个 UI 截图怎么操作 / 这个软件界面是干嘛的

## 图表 / 数据

- 这个图表说明了什么 / 分析这张图表 / 解读这个数据图 / 这个曲线图是什么意思
- 帮我看看这个统计图 / 这个柱状图/折线图/饼图说明了什么 / 图里的数据趋势是什么

## 数学 / 题目

- 这道题怎么做 / 帮我解一下这道题 / 看下这道数学题 / 这题怎么算
- 帮我检查一下这个计算过程 / 这个算式对不对

## 代码截图

- 分析这个代码截图 / 这段代码有什么问题 / 帮我看看这个代码报错
- 这个代码片段是干嘛的 / 帮我解释一下这段代码 / 这个代码截图里的 bug 在哪

## 文档 / PDF / 扫描件

- 读一下这份文档 / 这个 PDF 讲了什么 / 解析这份扫描件 / 帮我提取文档里的信息
- 这份合同/论文/报告的重点是什么 / 帮我总结这份文档
- 这个文档里的表格数据是什么

## 其他常见说法

- 帮我识别这个 logo / 这个标志是什么 / 这是什么植物/动物/物品
- 图片里的这个是什么品牌 / 这个车/包/表是什么型号
- 帮我翻译图片里的文字 / 把图里的英文翻译成中文
